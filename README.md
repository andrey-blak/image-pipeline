# image-pipeline

Batch image transformation tool. Reads images from an input folder, applies a configurable, ordered pipeline of transformations (trim borders, rotation, resize, auto-brightness, saturation, etc.), and writes the results, renamed if needed, to an output folder. Originals are never modified.

Python package: `imgpipe`. Pipeline configuration is TOML.

**Status: skeleton.** No functionality yet. See `AGENTS.md` for the layout and conventions.
